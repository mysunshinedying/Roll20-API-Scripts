# 개요
저널 토큰을 복제하여 저널과 연결되지 않은 토큰들을 만들어주는 API입니다. `token_bar_tracker`와 같이 이용하면 좋습니다.

AR2E, DX3rd와 같은 몹이 많으나 저널이 필요한 경우에 사용하기 편합니다.

---

## 사용 법
1. 먼저 복사하려는 저널의 토큰을 맵에 생성합니다.
2. 해당 저널에서 나타내려는 바를 설정합니다.
3. 이후 해당 토큰을 클릭한 뒤 채팅창에 `!copyToken --개수`를 입력하면 복사됩니다.
4. A-Z까지의 개체가 추가됩니다.

---

## 주의사항
- 모든 토큰은 기본적으로 모두에게 공개 처리 되어있습니다. 옵션을 통하여 ON/OFF 처리 예정에 있으나 현재는 공개 상태임에 유의해주세요.
- 저널과 연결되지 않은 독자적인 토큰이 만들어집니다. 이에 따른 관리는 GM이 직접 판단하도록 합니다.
